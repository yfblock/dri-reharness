Reharness 架构设计

从 C 驱动源码到三个确定性后端的完整流水线，以及 QEMU 验证和 Strict Readiness Gate。
提取器内部各模块的依赖关系：从 libclang 解析到 dataflow + taint 分析，再到 call graph inlining 和 FormalRIS 构建。
抽象值域与污点追踪：BasePtr 来自 ioremap，Offset 是解析后的寄存器宏，ReadTaint 是 readl 返回值。三者联动检测 RMW 模式。
四种 IR 产物各自的角色：.ris 回答"寄存器怎么被访问"、.dspec 回答"这些访问意味着什么"、.bind 回答"怎么映射到运行时"、.facts 提供"LLM 重建需要的源码事实"。
各 Python 模块的代码行数和代码库关键指标。
